# Student Management System

A beginner-friendly console-based Student Management System built using Python.

## Features

- Add student details
- View all students
- Search student by roll number
- Delete student by roll number
- Automatic grade calculation based on marks
- Simple menu-driven interface

## Grade System

| Marks | Grade |
|------:|:------|
| 90+ | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |

## Technologies Used

- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input
