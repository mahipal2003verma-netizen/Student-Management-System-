# ✅ To-Do List App

A simple Python-based To-Do List application that helps users manage their daily tasks through a command-line interface.

## 🚀 Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Search tasks by name
- Delete tasks
- Handles invalid input
- Simple command-line interface

## 🛠️ Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements
- Exception Handling
- User Input

## ▶️ How to Run

Make sure Python is installed.

Run:

```bash
python main.py
